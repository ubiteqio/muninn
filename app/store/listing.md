## App Review information

Apple's reviewer has to sign in to a working server. That needs a Muninn server reachable from
the internet over HTTPS with a demo account, which does not exist yet (see the open points in
`CLAUDE.md`). Until then the listing can be saved but not submitted for review. Once it exists:

- **Sign-in required:** yes, username and password of a demo account on that server.
- **Notes:**

<!-- field: review.notes -->
```
Muninn is the client for a self-hosted photo library server. On first launch, enter the server address below, then sign in with the demo account. The demo library contains only CC0 photos and invented names.

Server: <https address of the demo server>
Username: <demo user>
Password: <demo password>
```

## App Privacy

**Data Not Collected.** Apple counts data as collected when it leaves the device in a way that
the developer or its partners can access. Muninn only talks to the server the family runs itself;
nothing reaches the developers. The one outside service is OpenFreeMap for map tiles, which sees
the IP address and the map area being viewed, but not the user's location or photos. That is
covered in the privacy policy and is not a data type Apple asks about.

## Age rating

Suggested answers: none of the content descriptors apply, no unrestricted web access, no
gambling, no in-app purchases. Comments exist but are visible only to the members of the family's
own server, not to the public. That gives **4+**. Apple's questionnaire decides in the end; if it
asks about user-generated content, the honest answer is that it is private to the family server.

## Encryption

Already answered in the build: `ITSAppUsesNonExemptEncryption` is `false` in `Info.plist`. The
app only uses HTTPS and the system keychain.
